# 치지직 이모티콘 단축키

치지직 채팅 입력창에서 **원하는 키 조합**으로 이모티콘을 넣는 Chrome Manifest V3 확장 프로그램입니다. 즐겨찾기, 여러 단축키 세트, JSON 가져오기·내보내기를 지원합니다. 기본 조합은 **Alt + 1~9**, macOS에서는 **Option + 1~9**입니다. 전송은 직접 Enter를 누릅니다.

## 설치와 업데이트

1. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램 로드**를 눌러 `manifest.json`이 들어 있는 폴더를 선택합니다. ZIP은 먼저 압축을 해제하세요.
3. 이미 열어둔 치지직 탭을 새로고침합니다.

업데이트할 때는 **기존에 설치한 폴더에 새 파일을 덮어쓰고**, 확장 프로그램의 **새로고침** 버튼과 치지직 탭 새로고침을 차례로 실행하세요. 기존 확장을 제거할 필요 없습니다. 다른 폴더에서 새로 설치하면 다른 확장 ID가 생길 수 있으므로, 이 경우 JSON으로 설정을 옮기세요.

0.1.x의 사용 여부, Alt/Alt+Shift 조합, 1~9번 등록값은 첫 실행 때 **기본 세트**로 자동 이관됩니다. 등록된 이모티콘은 즐겨찾기에도 추가됩니다. 원래 저장 키도 보존하지만, 0.2.x에서 한 변경은 구버전에 역반영되지 않습니다.

설치·실행에는 Node나 npm이 필요하지 않습니다.

## 이모티콘 등록과 키 지정

1. 로그인한 방송의 채팅 입력창 옆 **⌨** 버튼을 누릅니다.
2. 슬롯의 **등록/변경**을 누릅니다.
3. 치지직 이모티콘 창에서 **해당 팩 탭**을 선택한 뒤 이모티콘을 클릭합니다. 최근 목록에서는 팩 정보를 알 수 없어 등록할 수 없습니다.
4. 슬롯 왼쪽 **키 버튼**을 누르고 원하는 조합을 입력합니다. 기본키를 그대로 써도 됩니다.
5. 채팅 입력창에 포커스를 두고 단축키를 누릅니다. 설정 패널과 이모티콘 창은 닫혀 있어도 됩니다.

- Ctrl/Alt/Command와 문자·숫자·기호 조합, F1~F12를 지원합니다. 숫자패드와 상단 숫자키는 같은 키로 취급합니다.
- 일반 문자 단독 입력, Shift+문자만 있는 조합, Enter/Esc/Tab/Space/삭제·이동 키, 수식키 단독은 지정할 수 없습니다.
- 같은 세트에서 키가 겹치거나 세트 전환키와 충돌하면 저장하지 않고 이유를 표시합니다. 서로 다른 세트에서는 같은 키를 재사용할 수 있습니다.
- 키 지정 창의 **단축키 해제**는 키만 지웁니다. 슬롯 오른쪽 **×**는 이모티콘만 지웁니다.
- 등록 과정에서는 채팅에 삽입하지 않습니다. Esc, 안내의 ×, 이모티콘 창 닫기, 설정 다시 열기로 취소할 수 있으며 60초 후 자동 취소됩니다. 등록 경고는 4.5초 후 사라집니다.
- 한글 조합 중이거나 다른 입력창에 포커스가 있으면 단축키를 실행하지 않습니다. 키를 길게 눌러도 반복 삽입하지 않습니다. 목록을 불러오는 동안 추가로 누른 키는 중복 작업을 막기 위해 생략됩니다.

브라우저·운영체제·다른 확장이 먼저 처리하는 조합은 사용할 수 없을 수 있습니다. `chrome://extensions/shortcuts`도 확인하세요. 예를 들어 드래그프리 확장이 Option+1/2를 사용하는 환경에서는 충돌했습니다.

## 즐겨찾기

**즐겨찾기** 탭에서 이모티콘을 검색하고 관리합니다.

- 슬롯에 등록하면 자동으로 즐겨찾기에 추가됩니다. **+ 이모티콘 추가**로 즐겨찾기만 등록할 수도 있습니다.
- **사용**은 해당 이모티콘을 채팅 초안에 넣습니다.
- **배치할 슬롯**을 선택한 뒤 **슬롯에 넣기**를 누르면 현재 세트에 재사용합니다. 슬롯의 키 조합은 유지됩니다.
- ↑/↓로 순서를 바꾸고 ★로 즐겨찾기를 해제합니다. 해제해도 기존 슬롯은 유지됩니다.
- 즐겨찾기는 모든 세트에서 공유하며 최대 200개입니다.

## 여러 단축키 세트

상단 세트 선택기로 전환합니다. **백업·세트 관리**에서 생성, 이름 변경, 복제, 삭제할 수 있습니다.

- 최대 9개 세트, 세트당 9개 슬롯입니다. 마지막 세트는 삭제할 수 없습니다.
- **단축키** 탭 아래에서 이전/다음 세트 전환키를 지정할 수 있습니다. 채팅 입력창에서 사용하면 끝에서 처음으로 순환합니다.
- 새 세트는 Alt/Option+1~9로 시작합니다. 세트 전환키와 겹치는 기본키는 미지정으로 둡니다.
- 활성 세트와 설정은 현재 브라우저의 치지직 탭에 함께 반영됩니다.

## JSON 가져오기·내보내기

**백업·세트 관리 → JSON 백업**에서 사용합니다.

- **내보내기:** 모든 세트, 활성 세트, 키 조합, 즐겨찾기, 사용 설정을 JSON 파일로 다운로드합니다.
- **가져오기:** 파일을 선택하면 세트·슬롯·즐겨찾기 개수와 세트 이름을 먼저 보여줍니다. 적용 전에는 설정을 변경하지 않습니다.
- **병합:** 가져온 세트를 별도 세트로 추가하고 즐겨찾기는 중복 없이 합칩니다. 기존 활성 세트와 설정을 유지합니다.
- **전체 교체:** 파일의 세트·키·즐겨찾기·설정으로 교체합니다.
- **이전 백업 복원:** 마지막 가져오기 직전 상태로 복원합니다. 복원 전 상태도 백업으로 바뀌므로 다시 복원하면 되돌릴 수 있습니다. 백업은 한 단계만 유지됩니다.

가져오기 전에 현재 상태를 자동 백업합니다. 미리보기를 연 뒤 다른 탭에서 설정이 바뀌면 적용을 거부하므로 파일을 다시 선택해 최신 상태에서 검토하세요. 손상된 파일, 잘못된 식별자·키 조합, 중복키, 제한을 넘는 데이터는 저장하지 않습니다.

지원 형식은 이 확장이 내보낸 `format: "chzz-shortcut"`, `version: 2` JSON이며, 최대 512KiB입니다. **Emozzk 등 다른 확장의 내보내기 형식은 지원하지 않습니다.**

## 동작과 데이터

치지직의 원래 이모티콘 버튼을 대신 클릭하므로 내부 채팅 초안도 함께 갱신됩니다. 초안 끝에 추가되며, 전송 버튼이나 채팅 전송 API는 호출하지 않습니다. 계정·구독·채팅 제한과 메시지 길이 제한은 치지직이 적용합니다. 팩 목록이 로딩 중이면 최대 5초 기다립니다.

권한은 `storage` 하나이고 콘텐츠 스크립트 범위는 `https://chzzk.naver.com/*`입니다. 서버, API 키, 원격 실행 코드는 없습니다. 미리보기는 네이버 `pstatic.net` CDN 이미지입니다. 설정은 로컬 확장 저장소에 보관하며, 직접 내보낸 파일도 사용자가 보관합니다. 확장을 삭제하면 확장 저장소 데이터는 삭제됩니다.

저장 변경은 확장의 백그라운드 처리기가 순서대로 적용합니다. 여러 탭에서 동시에 수정해도 오래된 전체 상태를 덮어쓰지 않도록 명령 단위로 처리합니다.

## 개발 및 검증

```sh
npm ci
npm run check
npm test
npm run package
```

`outputs/chzz-shortcut/`에 설치용 폴더, `outputs/chzz-shortcut-<버전>.zip`에 ZIP을 만듭니다. ZIP 생성에는 `zip` 명령이 필요합니다.

자동 테스트는 원래 채팅 입력 경로, 팩 로딩, IME·포커스, 토스트 취소, 설정 이관, 키 충돌, 세트 전환, 즐겨찾기 재사용, JSON 미리보기·검증·병합·교체·복원, 동시 저장, 저장 실패를 확인합니다. 실제 채팅 전송은 테스트하지 않습니다.
